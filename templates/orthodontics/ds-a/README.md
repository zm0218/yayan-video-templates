# DS模版A · 正畸门诊合作升级视频

输入 **门诊名称 + 门诊Logo**，沿用固定八场景、白蓝视觉、真实 DeepSmile 标识和中文女声。标准64秒、1920×1080、30fps、H.264/AAC、无BGM；长名称的旁白超出预留时长时同步延长场景。

## 固定场景

患者关切 → 清晰沟通 → 双品牌合作与四项升级 → 看懂检查情况 → 方案与阶段目标 → 过程追踪 → 消费者利益 → 咨询收束。

沟通与利益场景使用 `communication-v03.png`，保留平板与托举手完整，固定 contain/right 取景；不重生人物图或另起视觉系统。AI人物为情景演绎，界面是去隐私的沟通示意。

## 参数

| 参数 | 用途 |
|---|---|
| `--name` | 门诊正式名称，必填 |
| `--logo` | PNG/JPG/JPEG/WebP/SVG原件路径，必填 |
| `--logo-has-name` | 看图确认Logo含名称时使用；避免页眉重复 |
| `--spoken-name` | 多音字/生僻字的配音写法，仅影响声音 |
| `--preview` | 离线八场景预览，无配音、无MP4 |
| `--allow-online-tts` | 允许将名称及三段公开文案发送给微软语音服务 |
| `--voice-dir` | 服务不可用或已有配音时，导入本机三段完整旁白；不联网 |
| `--out` | 新的独立任务目录 |
| `--resume` | 仅恢复相同输入、模板指纹和模式的任务 |

从项目根目录，通过 `video.py --template ds-a` 调用；详细安装与命令见根 README。

## 成片命名

固定为 **`DeepSmile-合作视频-门诊名称.mp4`**。文件名必须以门诊名称结尾，不追加日期、版本或“样片”等字段。

## 语音规则

必须先读 [语音流程与规范](../../../docs/VOICE.md)。同一晓晓女声、+29%原生语速、+2Hz音高；沟通、合作、片尾3段整句生成，另5段通用声音复用。显示文案与TTS纠音输入分开，不拆字拼接，不截断声音。原通用音轨没有完整听感终审结论，新片必须逐次看听，不因模板固定就跳过。

## 内容边界

不自动添加地址、价格、活动、电话、连锁身份或“独家/唯一”。双品牌合作片应仅用于真实、获准的合作宣传。保留情景演绎、界面示意和医生结合检查作出诊疗决定的文字，不暗示AI替代医生或保证疗效。

制作后按照 [验收清单](../../../docs/QA.md) 查看实际成片关键帧并完整听审。默认状态是「有旁白样片」，不能把媒体检查通过当作完整视听验收通过。
