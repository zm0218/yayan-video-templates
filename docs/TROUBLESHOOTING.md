# 故障处理

## 首次配置失败

先确认当前目录包含 `package.json`、`requirements.txt` 和 `bootstrap.py`。使用 Python 3.10+、Node 20.9+；推荐 Python3.12、Node22或更新LTS。

- 找不到 Python / Node：从官方安装包安装所缺基础环境，重开终端后再检查。不要全局安装随机补丁。
- npm/pip 下载失败：区分网络、证书、代理和权限；保留原始错误。不要关闭 TLS 校验或把密钥写入命令/仓库。
- 不同操作系统：不要把别人的 `.venv/`、`node_modules/` 复制过来，运行本机 `bootstrap.py`。
- 已有特定运行时：可在未跟踪的根 `runtime.local.json` 配置 `node`、`sharp`、`ffmpeg`、`ffprobe` 绝对路径；或使用 `NODE_BIN`、`SHARP_MODULE`、`FFMPEG_BIN`、`FFPROBE_BIN`。配置不要公开提交。
- 系统隔离、网络或安装审批按当前 Codex 环境处理；仓库规则不替代用户授权。

## 配音网络失败

保留终端显示的任务目录，确认能访问微软在线语音后，用完全相同参数追加 `--out '任务目录' --resume`。已完成并通过哈希校验的整句音频会复用；不删除整条任务，也不拿旧门诊音频凑数。先看画面可另开任务用 `--preview`。

HTTP 403 表示请求被服务拒绝，不等于缺少文件或本机编码器错误。先检查 edge-tts 官方版本、系统时间及服务状态；不关闭证书校验、不绕过访问限制，不连续盲重试。2026-10-12 发布验证中，最新版7.2.8在新旧本机环境都返回403，时钟正常，具体拒绝原因未确认。需要继续制作时可在新任务以 `--voice-dir` 导入获准的三段整句音频。

## 恢复时提示输入不同

检查名称、Logo原件、`--logo-has-name`、`--spoken-name`、模板版本和预览/视频模式。改变任何一项请用新目录。更改读音后的任务不能复用之前的请求记录。

## 中文方框或字体不一致

检查模板的 Noto OTF 字体哈希、输出目录的 `fonts.conf` 和预览实图。默认只配置项目字体，不依赖中文系统字体，也不安装到系统目录。环境检查通过仍需查看中文是否真实显示。

## 无声、双层字幕或播放了旧版

先核对播放器当前文件的完整路径、`delivery.json` 和实际音轨；再查播放器静音、音量、输出设备、音轨与外挂字幕。字幕已经烧入画面，不要再自动加载制作源里的 SRT。不要没有证据就改声道、编码或重配音。

## 文件名错误

DS模版A固定为 `DeepSmile-合作视频-门诊名称.mp4`。日期与版本在父目录；状态在记录里。文件名禁用字符会报错，先确认门诊适用名称，不自行缩写。
