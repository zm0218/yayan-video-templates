# 语音流程与规范

本文件是仓库自带规则，不要求安装 yy-video。下面的精确声音配置适用于 **DS模版A**；后续美白模板须在自己的说明中登记声音配置，不自动继承另一条业务线的文案。

## 固定声音配置

| 项目 | DS模版A |
|---|---|
| 服务入口 | `edge-tts`，微软 Edge 在线语音服务 |
| 女声 | `zh-CN-XiaoxiaoNeural` |
| 原生语速 | `+29%` |
| 音高 | `+2Hz` |
| 新生成 | understand（沟通）、partnership（合作）、closing（片尾）共3段 |
| 复用 | opening、analysis、plan、progress、benefits 共5段通用声音 |
| 内部音频 | 48kHz / 单声道 / 16bit PCM WAV |
| 交付音频 | AAC 192kbps，与画面封装在 MP4 内 |
| BGM | 默认无背景音乐 |

固定通用音频不包含旧门诊名称，原始哈希保存在模板 `assets/manifest.json`。三段个性化声音必须按**整句/整场景**重配，禁止把门诊名称嵌进旧声音，禁止拆字、拼音节、强拉某个字的音高。

## 授权与发送内容

首次运行前，使用者应知道并授权：本次门诊名称和三段公开宣传文案会发送至微软在线语音服务。显式参数为 `--allow-online-tts`。Logo、图片及患者资料不随配音上传。

README 中给同事的话术已包含这一说明和授权。用户已有同用途授权时沿用，不要求每条重新确认；没有授权时不能把下载仓库或其他人的授权当作同意。`--preview` 不请求在线语音。

`edge-tts` 是访问在线服务的开源客户端；网络或上游服务变化会影响可用性。不要把它描述成有稳定性承诺的商业语音 API。来源：[edge-tts 项目](https://github.com/rany2/edge-tts)。

## 文本与读音分离

- 屏幕字幕、脚本、文件名始终使用正确文字「正畸」「数智化」和门诊正式名称。
- 仅 TTS 输入使用当前验证流程中的读音写法：`正畸 → 正基`、`数智化 → 数质化`、`DeepSmile → Deep Smile`。
- 多音字或生僻名称可传 `--spoken-name '配音用的同音名称'`。这只影响声音，不改变字幕或文件名。
- 同音写法只是纠音手段，不等于听感通过。「畸」应读一声，「智」与整句连读都需实际试听。
- 不在「数智化」中间加逗号，不拆词制造停顿。读音不合格时调整 TTS 输入并整句重配，重新核对时间轴。

## 完整流程

1. 替换门诊名称并保存显示文本与 TTS 文本；确认三段发送内容符合授权。
2. 生成3段门诊旁白，保存原始 MP3、请求内容、边界数据和哈希。
3. `ffprobe` 确认每段时长为有效正数；空文件或请求异常立即停止，不继续封装。
4. 采用 `loudnorm=I=-17:TP=-1.5:LRA=8`，开头144ms缓冲，尾部补齐，转为48kHz单声道 WAV。
5. 场景时长至少覆盖真实旁白长度加缓冲，向上对齐30fps；过长名称自动延长对应场景，不截断旁白，也不单独强行加速。
6. 与5段通用声音拼合，核对每段采样数、8段时间轴连续性，随后生成画面、字幕及进度。
7. 封装成 AAC；检查音频信号、媒体时长和完整解码，导出片尾试听及实际视频关键帧。
8. 完整看听成片，重点听门诊名称、两处「数智化正畸」、片尾连读、停顿与转场。确认无机械拼接、截尾、突兀音量或意外静音。

## 中断与重配

### 服务不可用时的本地整段旁白

默认仍使用上述微软在线配音。当服务拒绝或使用者已有获准的整段配音时，可在新任务指定 `--voice-dir '本地音频目录'`，不发起在线请求。目录中必须各有且仅有一份 `understand.mp3`、`partnership.mp3`、`closing.mp3`（也支持对应 `.wav` / `.m4a`）。三段内容必须与本次门诊名称和场景文案一致；不要复用其他门诊的声音。

程序保留原始音频、记录哈希，继续执行同样的时长、响度、字幕和画面同步流程；状态明确记为 `provided-whole-scene`，不会冒充本次在线生成。仍需核对声音的一致性和实际听感。修改为本地旁白时新建目录，不拿旧在线请求做错误恢复。

### 恢复在线任务

保留任务目录，用相同输入加 `--out '原任务目录' --resume` 恢复。缓存按声音参数、TTS 文本和音频哈希校验，已完成的整段可复用。输入、模板版本或预览/视频模式改变时必须新建任务，不能错误复用旧门诊旁白。

变更 `--spoken-name` 应建立新任务；旧样片保留。语音文本、音频、字幕与时间轴都属于制作源，不放进只含 MP4 的交付目录。

技术检查、声波图、声调曲线、音轨存在都不能代替实际听辨。未完成完整听审时保留「有旁白样片」状态，不能宣称声音已正式验收。
