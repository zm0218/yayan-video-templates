# 视频验收清单

按本次实际完成范围记录通过、失败、待验证；代码或工具检查不能代替看图与听声音。

## 每次制作

- 输入：门诊正式名称与 Logo 对应；原图完整；已带名称时不重复添加；真实合作关系适用。
- 来源：使用模板固定图片、真实品牌标识、项目字体；没有旧门诊名、患者姓名、病例编号或其他非公开信息。
- 技术：8场景时间轴连续；1080p / 30fps；H.264 + AAC；音频有效且声画时长一致；完整解码无错误。
- 画面：查看 `qa/final-*.jpg` 与转场前后；Logo 未拉伸/裁切，中文无方框，字幕无重叠或突变，界面与人物视角一致。
- DS模版A：约8秒及52秒的沟通/利益画面要看平板、托举手和字幕区；因长旁白延长时，按实际 `scene-timing.json` 定位场景，不死用秒数。
- 声音：按 [VOICE.md](VOICE.md) 检查门诊名称、「正畸」「数智化」、整句自然度和片尾连读。
- 完整播放：打开准确交付文件并连续看听；播放器静音、音轨选择和外挂字幕要核对。
- 交付：`renders/` 只有约定的 MP4，文件名以门诊名称结尾；SRT/ASS 和静音母版不随成片混放。

## 状态记录

`delivery.json` 默认保留 `visualReview`、`fullPlaybackReview`、`listeningReview` 为 `pending`。实际看过关键帧只可更新画面抽查结论；完整看听完成后，才能逐项记录相应结论、文件及日期。没有实际执行的检查不能记为 passed。

最终商用前由使用者确认品牌合作与对外使用范围。模板生成的是情景/沟通示意，诊疗判断由医生结合检查作出，不暗示自动诊断或保证疗效。
